## 🧠 About Me

I'm an AI Engineer building **production-grade agentic LLM and RAG systems** — the kind that go into Fortune 30 companies and actually move the needle. My work spans deep agent architectures, multi-repository code intelligence, and enterprise retrieval systems that combine semantic search with structured analysis at scale.

> *Most of what I build is proprietary. But the ideas, the lessons, and the thinking? Those are public.*

- 🤖 Architecting **Deep Agent** and **multi-agent systems** for cross-repository reasoning
- 🔍 Building **hybrid retrieval systems** (semantic + keyword + LLM re-ranking) at enterprise scale
- ⚙️ Automating **SDLC workflows** — ingestion, code understanding, test generation
- 🧪 Fine-tuning **Llama 3.1, Phi-3, Gemma, Mistral** with LoRA/QLoRA
- 📍 Irving, TX
